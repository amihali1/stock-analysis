# Model Registry

Track trained models, their hyperparameters, and performance metrics.

## Format

```
### Model Name (version)
- **Type**: algorithm
- **Trained**: date
- **Dataset**: description
- **Hyperparams**: key params
- **Metrics**: accuracy, precision, recall, etc.
- **File**: path to serialized model
- **Notes**: anything notable
```
